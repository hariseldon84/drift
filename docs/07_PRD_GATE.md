# Drift Browser — PRD Gate

The PRD is intentionally **not yet written**.

Per product process, it should be created only after the preceding decisions are reviewed and frozen.

Before PRD creation, explicitly approve or revise:
1. Product Thesis & Innovation Pillars
2. Competitive Validation conclusions
3. Capability Universe
4. Technical Architecture
5. V0 MLP scope
6. V1 Scale scope

Specific PRD blockers still requiring freeze:
- V0 launch OS: Mac first, Windows first, or simultaneous
- exact V0 object taxonomy
- whether Research Mode is beta in V0 or strictly V1
- V0 account requirement
- sync timing
- exact Free vs Pro packaging
- cloud model/provider strategy
- local model hardware minimums
- exact V0 comparison verticals beyond products
- browser fork/update strategy
- data retention/privacy policy
- target performance budgets
- V0 launch success thresholds

Once these are frozen, create `07_PRD.md`.
